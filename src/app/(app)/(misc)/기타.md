# 기타 (내 업무)

관리팀 계정(관리자·담당자) 모두 쓰는 영역입니다. 주소는 /misc 아래입니다.

| 화면 | 주소 | 저장 (settings 표) |
|---|---|---|
| 대시보드 (월별 캘린더 포함) | /misc | - |
| 주간업무일지 (내 일지·팀 모아보기·지난 일지, 인쇄·엑셀) | /misc/weekly | `wk:<사용자>:<월요일>` |
| 타부서 업무협조 (품질·생산·영업·구매·연구소) | /misc/coop | `coop:<번호>` (한 건씩) |
| 개인일정 (반복 일정) | /misc/plan | `plan:<사용자>` |
| 월별 캘린더 | /misc/calendar | - |
| 진행 건·할 일 대장 (관리자만) | /misc/b/tasks | ledger_rows |

- 자료 모양·계산: src/lib/기타/work.ts, 읽고 쓰기: workStore.ts, 캘린더 자료: calendar.ts
- 엑셀: /api/misc/weekly?w=<월요일>&who=me|team
- 기한 있는 업무협조와 7일 안 개인일정은 통합 대시보드 '이번 주 할 일'에도 나옵니다 (src/lib/대시/data.ts todos).
