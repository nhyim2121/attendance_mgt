# 근태관리통합시스템 (관리팀용)

캡스 월별 출입기록(`N월 근태현황.xls`)과 하이웍스 신청서를 정리한 `근태현황(2026년~).xlsx`를 올리면

- 수작업으로 만들던 **직원별 시트**(B2 `부서 이름`, 4행 헤더, 날짜별 출근·퇴근 1줄씩)를 자동으로 만들고
- 근무형태(`정상(08:30)`, `연장(20:00)`, `휴일(17:30)`)를 채우고, 연차·출장 등을 반영해
- 지각·조퇴·기록 누락·휴가 사용을 대시보드로 보여 줍니다.

관리팀이 사내망에서 접속해 쓰는 **사이트**입니다. 로그인한 담당자만 볼 수 있고, 올린 파일과 기입한 내용은
서버 PC의 공용 저장소(`data/db/caps.sqlite`)에 저장되어 모두가 같은 데이터를 봅니다. 외부 클라우드로는 나가지 않습니다.

## 메뉴

| 메뉴 | 하는 일 |
|---|---|
| 홈 | 출근/지각/미출근/휴가 카드, 출퇴근 누락, 관리가 필요한 직원, 근로시간 리포트, 휴가 현황 |
| 일일 현황 | 그날 캡스 파일을 올리면 출근·퇴근·지각·미출근·휴가·출장 인원을 자동 집계, 상태별 이름, 직원별 출퇴근 |
| 일일 근태현황 | 날짜별 근태현황 보고서 등록·수정·삭제 (근태현황·휴가일정·휴일근무·도제), 근태현황 파일/전일 보고서 불러오기, 이미지 저장·복사, 하이웍스 메일 발송 |
| 출퇴근기록 | 직원 1명의 날짜별 출퇴근 그래프, 근태현황 시트, 하이웍스 기록, 캡스 원본 |
| 근태 기입 | 직원·월을 골라 출퇴근 시각, 근무형태(조출·연장 등), 근무지, 비고를 표에서 직접 수정 → 저장 (수정자·시각 기록, 되돌리기 가능) |
| 직원별 시트 | [N월 전체]+[요약]+직원별 시트 엑셀, 개인별 ZIP 내려받기 (기입한 내용 반영) |
| 파일 업로드 | 캡스 월별 파일(여러 개)·근태현황 파일 저장, 업로드 이력, 잘못 올린 업로드/월 삭제(관리자) |
| 사용자 관리 | 계정 추가·역할 변경·비밀번호 초기화·삭제(관리자), 내 비밀번호 변경(모두) |

역할: **관리자** = 모든 기능 + 삭제 + 사용자 관리 / **담당자** = 조회·업로드·기입·설정.
근무 기준과 공휴일(사이드바)은 모든 사용자에게 공통으로 적용됩니다.

│   ├── analytics.py          # 일별 근태 판정, 근무형태 표기, 기입값 반영, 대시보드 집계

├── scripts/
│   ├── add_user.py           # 서버 PC에서 계정 만들기 (첫 관리자 계정)

│   └── make_sample.py        # 가짜 샘플 파일 생성
├── data/db/                  # 공용 저장소와 백업 (git 제외, 개인정보)
└── tests/                    # pytest

## 서버 PC 설치 (처음 한 번)

Python 3.12가 설치된 PC에서 PowerShell로:

```powershell
cd $HOME\caps-attendance-app
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
.\.venv\Scripts\python.exe scripts\add_user.py      # 첫 계정은 자동으로 '관리자'
```

## 사이트 켜기

1. 처음 한 번 `powershell -ExecutionPolicy Bypass -File scripts\server_control.ps1 install`로 작업 스케줄러에 등록합니다 (이후 로그인 시 자동 실행, `site_restart.bat`으로 바로 켜기).
2. **처음 켤 때 Windows 방화벽 창이 뜨면 '개인 네트워크'에 체크하고 '액세스 허용'** 을 누릅니다.
   (회사 보안 정책으로 막혀 있으면 전산 담당자에게 TCP 8501 포트 허용을 요청하세요.)
3. 관리팀 다른 PC의 브라우저에서 `http://서버PC의IP:8501` 로 접속합니다. 서버 창에 IPv4 주소와 Streamlit의 "Network URL"이 표시됩니다.
   서버 PC와 같은 네트워크(같은 공유기·Wi-Fi 또는 사내망)에 있어야 합니다. Wi-Fi는 IP가 바뀔 수 있으니 매번 창에 나온 주소를 확인하세요.
4. 관리자는 **사용자 관리**에서 팀원 계정을 만들고 처음 비밀번호를 직접 전달합니다.

**백그라운드 실행 (작업 스케줄러, 2026-10-26부터):** 사이트는 창 없이 백그라운드에서 돌아갑니다.
- Windows에 로그인하면 작업 스케줄러의 `CAPS 근태 사이트` 작업이 `scripts/run_server.py`(감시기)를 실행합니다.
- 감시기는 사이트가 멈추면 5~60초 뒤 자동으로 다시 켭니다. 감시기 자체가 멈춰도 5분마다 점검해서 다시 켭니다.
- 프로젝트 폴더의 파일을 더블클릭해서 관리합니다:
  - `site_status.bat` — 켜져 있는지, 접속 주소, 최근 재시작 기록
  - `site_restart.bat` — 다시 켜기 (코드를 바꾼 뒤에도 이걸로 반영)
  - `site_stop.bat` — 끄기 (자동 재시작도 멈춤, 다시 켜려면 site_restart.bat)
- 기록: `data/logs/watchdog.log`(켜고 멈춘 기록), `data/logs/server-날짜.log`(사이트 출력)
- `start_server.bat`은 창을 띄워 직접 실행할 때만 씁니다. 백그라운드 사이트가 켜져 있으면 포트가 겹치니 먼저 `site_stop.bat`을 실행하세요.
- 자동 실행을 완전히 없애려면: `powershell -ExecutionPolicy Bypass -File scripts\server_control.ps1 uninstall`

서버 PC가 꺼지거나 절전 모드가 되면 사이트도 멈춥니다. 늘 켜 두는 PC에서 실행하세요.
저장소는 켤 때마다 `data/db/backup/`에 백업됩니다.

## 하이웍스 메일 설정

1. `.streamlit\secrets.toml.example`을 같은 폴더에 `secrets.toml`로 복사합니다 (git 제외, 서버 PC에만 둠).
2. `user`(보내는 메일 주소)와 `password`를 적습니다. 서버는 `smtps.hiworks.com:465`(SSL)입니다.
3. 하이웍스 관리자 설정에서 외부 메일 프로그램(SMTP) 사용이 허용되어 있어야 합니다.
4. 사이트를 다시 켜면 **일일 근태현황 → 하이웍스 메일로 보내기**가 활성화됩니다. 받는 사람·참조는 마지막 발송값이 기본으로 남습니다.

사이트에서 저장한 일일 근태현황은 근태 판정에 바로 반영되며, 같은 날짜는 근태현황 파일보다 사이트 내용이 우선합니다.
폰트(Paperlogy)는 `static/fonts/`에서 제공됩니다 (`server.enableStaticServing = true`).

## 홈 대시보드 지표

- 카드(기준일): 출근 = 출퇴근 기록이 있는 인원, 지각, 미출근 = 평일인데 기록·휴가 모두 없음, 휴가 = 연차·반차·공가 등
- 출퇴근 누락: 미출근 / 출근 누락 / 퇴근 누락 (최근 날짜 먼저)
- 관리가 필요한 직원: 지각 3회 이상, 누락 3회 이상, 연장·휴일 12시간 이상, 휴일 출근, 명단에 없는 출입자
- 리포트 현황: 소정근로(평일 × 8h), 실제근로(08:30 이전 출근은 08:30부터, 휴게 1h 제외), 연장근로, 휴일근로
- 휴가 현황: 1월 1일부터 기준일까지 연차 사용(연차 1, 반차 0.5, 반반차 0.25) / 기준일수(기본 15일, '기준'에서 변경), 공가 일수

## 처리 규칙

**캡스 파일**
- 파일 안에서 `발생일자·발생시각·이름` 열이 있고 행이 가장 많은 시트를 원본으로 씁니다
  (`Sheet1`, `3월 근태현황`, `9월 전체(~27일)` 등 이름은 상관없음).
- 모드 `해제`·`세트`(경비 설정)는 근태 판정에서 빼고, `[N월 전체]` 시트에는 그대로 둡니다.
- 하루 출근 = 첫 `출근` 태그(없으면 첫 태그), 퇴근 = 마지막 `퇴근` 태그(없으면 마지막 태그).
- 여러 달 파일을 한꺼번에 올리면 합치고 중복은 하나만 남깁니다.

**근태현황 파일**
- `명단` 시트의 부서를 직원에게 붙이고, 사이드바의 "명단에 있는 직원만"으로 외부 인원을 거릅니다.
- 날짜 시트(`26.10.27(화)`)의 첫 번째 표에서 `o` 표시된 연차·반차·반반차·외출·공가·출장·교육·외근을 읽습니다.
  비고에 `10/15(목) 근태`라고 적힌 줄은 그 날짜로 반영합니다.
- 기간 시트(`26.04.04~04.05(주말)`), 참고 시트, 아래쪽 '휴가일정 관련' 같은 참고 표는 읽지 않습니다.

**판정**
- 지각: 평일에 출근이 `08:30 + 유예`보다 늦음 / 조퇴: 평일에 퇴근이 `17:30`보다 이름.
  그날 반차·반반차·외출·출장·교육·외근·연차·공가 신청이 있으면 판정하지 않습니다.
- 기록 없음: 평일인데 출입기록도 하이웍스 근태도 없음 (그 직원의 첫 기록~마지막 기록 사이만).
- 근무형태: 원본에 값이 있으면 그대로 씁니다. 없으면 수작업 시트처럼 특이한 날만 적습니다:
  퇴근이 17:30+60분 이후면 `연장(30분 단위 절사)`, 주말·공휴일은 `휴일(시각)`,
  출장·교육 날 채운 시각은 `정상출근(08:30)`/`정상퇴근(17:30)`. 조출처럼 승인이 필요한 항목은 직접 고쳐 주세요.
- 출장·교육·외근 날: 출근이 없거나 08:30보다 늦으면 08:30, 퇴근이 없거나 17:30보다 이르면 17:30을
  인증 `하이웍스`로 채우고, 같은 날 같은 일행 이름을 비고에 적습니다. '휴일근무 관련' 표의 작업내용은 근무지로 씁니다.
- 예외 행: 근무기록이 없거나 출근·퇴근 중 하나만 있는 날은 **날짜와 요일만 적고 나머지는 비웁니다**
  (대개 휴가 또는 미연동). 엑셀에서는 연한 회색으로 표시됩니다.
- 출근은 첫 `출근` 태그, 퇴근은 마지막 `퇴근` 태그만 씁니다 (`출입` 태그는 퇴근으로 보지 않음).
- 근무 기준, 연장 기준, 공휴일(회사 휴무일 포함)은 사이드바에서 바꿀 수 있습니다 (모든 사용자 공통).
- 근태 기입에서 고친 값이 있으면 위 규칙보다 우선합니다. 시각을 직접 넣은 행은 인증 칸에 `수기입력`으로 표시됩니다.
