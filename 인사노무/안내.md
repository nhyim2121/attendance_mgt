# 인사노무

근태·휴가·직원·조직도 업무 자료(근로계약서, 휴가 신청서 사본, 하이웍스 내려받은 파일 등)를 두는 곳입니다.

## 근태·휴가 프로그램은 어디에?

- 사이트: 인사노무 메뉴 (근태 홈 /attendance, 휴가 홈 /leave)
- 프로그램 코드: `src/app/(app)/(hr)`(화면), `src/lib/인사노무`(계산), `src/components/인사노무`(화면 조각)
- 근태 데이터베이스 백업: `데이터/db/backup` (데이터가 바뀌면 자동, 오래 보관할 것은 `데이터/db/backup-keep`)
- 사이트 기록: `데이터/logs`
- 코드 변경 기록: 매일 18:00 자동 커밋 (GitHub)

## 폴더 쓰는 법

- **자료**: 이 업무의 문서·엑셀·스캔본을 여기에 넣고 작업하세요. 하위 폴더를 마음대로 만들어도 됩니다.
- **백업**: 자료 폴더가 바뀌면 매일 18:00(그리고 사이트를 켤 때) 자동으로 `자료-날짜-시각.zip`이 만들어집니다. 최근 30개를 남깁니다.
- **작업기록.md**: 백업할 때 추가·변경·삭제된 파일 이름이 자동으로 적힙니다. 직접 메모를 적어도 됩니다.
- 바로 백업하려면: 터미널에서 `node 자동실행/backup-files.mjs`
- 자료·백업·작업기록은 개인정보가 있을 수 있어 **GitHub에 올라가지 않고 이 PC에만** 있습니다.
